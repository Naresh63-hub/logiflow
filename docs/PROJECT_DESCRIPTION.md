# LogiFlow — Project Description

**LogiFlow** is a production-quality, cross-platform Third-Party Logistics (3PL) Shipment Tracking and Proof-of-Delivery (POD) mobile application built with Flutter, Dart, Riverpod, GoRouter, Supabase PostgreSQL, and Drift SQLite. Designed specifically to solve operational challenges for regional logistics hubs operating in Noida and the Delhi National Capital Region (NCR)—including central sorting facilities in Noida Sector 62, fulfillment hubs in Greater Noida West, and gateway centers in Okhla—the system empowers shippers, hub managers, and last-mile delivery personnel to manage the complete parcel lifecycle seamlessly across both high-speed networks and zero-connectivity environments.

At the core of LogiFlow is a resilient **offline-first architecture** powered by a strongly-typed Drift SQLite database and an automated background synchronization engine. Field delivery personnel and warehouse operators frequently work inside underground loading bays, industrial basements, or rural highway corridors where cellular data drops intermittently. Rather than blocking user workflows or losing vital shipment state, every consignment manifestation, barcode scan, status transition, and Proof-of-Delivery submission is persisted immediately to local SQLite storage and appended to a persistent First-In-First-Out (FIFO) synchronization queue. When network connectivity is restored, the synchronization engine automatically flushes queued operations to Supabase using optimistic concurrency control (`version` integers and `updated_at` timestamps) along with a deterministic conflict resolution engine that guarantees critical delivery evidence—such as digital receiver signatures, camera photographs, and GPS coordinates—is never overwritten or discarded.

The application implements strict role-based access control at both the presentation layer and the PostgreSQL Row Level Security (RLS) layer, differentiating workflows for **Shippers** (consignment creation, real-time tracking timelines, POD verification) and **Hub Managers** (inbound sorting, barcode/QR scanning, dispatch updates, driver assignments, and POD collection). Built with Material Design 3 aesthetics, the interface supports instant Light/Dark mode switching and dynamic English and Hindi (हिंदी) localization without requiring an application restart.
